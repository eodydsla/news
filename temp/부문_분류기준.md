## 1. 부문 체계

| 부문 | 한 줄 정의 |
|---|---|
| **대기질** | 공기의 상태에 대한 서술 |
| **대기정책** | 그 상태를 바꾸려는 공적 개입 |
| **건강** | 대기오염이 인체에 미치는 영향 |
| **생활** | 시민이 대기오염에 대응하는 행동과 생활공간 |

대기질은 **관측의 언어**, 대기정책은 **결정의 언어**다.

## 2. 판정 파이프라인

```
[0-1] 대기 관련성      대기 앵커가 없으면 → 무관
[0-2] 장르 배제        날씨/예보·기업/증시·부동산·종합브리핑 → 무관
[1]   부문 점수        ①단독 = 무조건 1점  ②조합 = AND 통과 시 1점  ③라우팅 = 동반어가 부문 결정
[2]   배정             argmax. 동점이면 대기정책 → 건강 → 생활 → 대기질
```

**0-1 대기 앵커**
`미세먼지` `초미세먼지` `대기오염` `대기질` `공기질` `대기환경` `황사` `스모그` `연무` `오존` `농도` `고농도` `대기오염물질` `매연` `분진` `질소산화물` `배출가스` `배출량`

**0-2 장르 배제** — 300건 표본의 **57.7%(173건)가 대기 기사가 아니었다.**

| 배제 장르 | 300건 중 | 탐지 단서 |
|---|---:|---|
| 날씨/예보 | 64 (21.3%) | 제목의 `[날씨]` `[오늘날씨]` `[내일날씨]` `[오늘의 미세먼지]` + `기온`·`강수확률`·`최저기온` 동시 등장 |
| 기업/산업/증시 | 35 (11.7%) | `통합 분류` 필드의 `경제>증권`·`경제>산업_기업` + 기업명 |
| 정치/행정 일반 | 29 (9.7%) | 대기 앵커가 제목에 없고 본문에만 1회 |
| 홍보/행사/교육 | 18 (6.0%) | `개강` `캠프` `박람회` `선정` |
| 생활연성 | 14 (4.7%) | 맛집·여행·다이어트 |
| 종합브리핑 | 7 (2.3%) | 제목의 `헤드라인` `주요뉴스` `브리핑` `브리프` |
| 부동산/분양 | 5 (1.7%) | `분양` `모델하우스` `재개발` |

> **날씨 기사를 무관으로 두는 이유**: 일기예보는 농도가 좋든 나쁘든 매일 나간다. 관심의 신호가 아니라 정례 정보다. 이걸 빼면 지수는 "공기가 나쁘다는 정보의 유통량"이 아니라 **"대기 문제가 사회적 의제로 다뤄진 정도"**를 재게 된다.

**동점 시 대기정책 우선**: 300건 중 정책 오배정 20건의 7건이 완전 동점이었고 종전 규칙(희소 부문 우선)이 대기질을 택하고 있었다. 이 한 줄로 정확도가 40.3% → 44.0%가 됐다.

## 4. 라우팅 — 부문 소속이 없는 물질·성분 50개

**물질명은 상태를 서술하지 않고 명명할 뿐이며, 실제 용법은 압도적으로 규제 쪽이다.**

| 물질 | 정책 키워드 동반율 |
|---|---:|
| 황산 95.5% · NOx 91.2% · SOx 88.9% · 질소산화물 88.1% · 황산화물 87.7% | |

```
물질 + 배출허용기준·저감장치·규제·환경부   → 대기정책
물질 + 호흡기·발암·천식                   → 건강
물질 + 농도·측정·초과·주의보              → 대기질
물질 단독                                 → 아무 부문도 켜지 않음
```

우선순위 **대기정책 → 건강 → 대기질**. 규제·건강 맥락이 더 특수하고 대기질은 기본값이라 마지막이다.

**대상 50개**: 광화학반응 휘발성 황산 대기유해물질 광화학 PAHs 유해대기오염물질 NH3 SO2 NO2 유기화합물 아황산가스 오존 벤젠 다환방향족탄화수소 이산화황 VOCs 특정대기유해물질 SOx 질산 블랙카본 이산화질소 에어로졸 NOx 연기 암모니아 비산먼지 나노입자 포름알데히드 HAPs 질소산화물 황산화물 분진 황산염 질산염 도로먼지 불산 일산화탄소 악취 카드뮴 중금속 발암물질 매연 입자상물질 미세플라스틱 유해물질 재비산먼지 탄소입자 CO 납

**효과 (300건)**: 정책→대기질 오배정 47건 → 14건, 정책 재현율 61.4% → 75.0%, 대기질 재현율 92.5% 유지.

## 10. 적합도 점수

```
적합도 = 1 + 9 × 판별우위도       (범용성 감점: DF ≥ 15% → −1, DF ≥ 30% → −2)
판별우위도 = (부문일치율 − 부문 기저구성비) ÷ (1 − 기저구성비)
```

**단독 자격은 적합도만으로 주지 않는다.** 적합도 6점 이상 **그리고** 무관 기사 등장률 40% 미만이어야 한다. 적합도는 사전이 자기 자신을 채점한 값이라 소속의 근거가 못 되고, 같은 소속 안에서의 상대 신뢰도로만 읽어야 한다.

## 12. 해석상 유의점

**날씨 기사를 빼면 대기질이 급감한다.** 종전 대기질 67건 중 48건이 일기예보 코너였다. 남는 19건은 오염 사태 보도·원인 분석·국제 비교·측정 기사다. 그 결과 **대기정책이 대기 기사의 64.6%로 최대 부문**이 되며, 기존 사전(대기질 64.5%)과 정반대 구도가 된다.

**중복은 결함이 아니라 현상이다.** `등급제`가 붙은 기사의 99.9%, `비상저감조치`의 92.9%가 대기질 키워드를 동반한다. 정책 기사는 반드시 대기질을 언급한다.

**키워드를 옮겨서는 중복이 줄지 않는다.** 대상 부문이 그만큼 커져 교집합이 유지된다. 빼거나 라우팅으로 돌려야 준다.

**2015년 건강에는 메르스가 섞여 있다.** 그해 `병원` 11.3%, `사망` 12.1%, `메르스` 5.6%.
