## 1. 날씨 기사 — 27,867건 (23%)  ← 제거 권고

「오늘의 날씨」류 예보. 제목에 대기어가 없고 본문 말미에 "미세먼지 농도 보통" 한 줄이 붙는다.

**중요 — 미세먼지 특화 예보는 여기 없다.** 사회>날씨 분류 기사 62,892건의 행선지를 보면:

| | 건수 | 어느 경로로 들어오나 |
|---|---:|---|
| 제목에 대기어 있음 | 29,056 | **1번 제목** — 이미 살아 있음 |
| 본문 앞 200자에 근접 언급 | 5,437 | **2번 붙어 나옴** — 이미 살아 있음 |
| 제목·본문에 없음 | 27,867 | 5번 날씨 ← 제거 대상 |

```
살아 있는 것   [날씨] 오락가락 비, 아침에 그쳐 오전까지 중부 미세먼지
               [날씨] 수도권 사흘째 비상저감조치...낮부터 약화
               [날씨] 사흘째 비상저감조치, 첫 초미세 경보...찬 바람 불며 해소
               [날씨] 탁한 공기 하늘 점차 흐려지며 비 소식

제거 대상       내일 아침까지 비, 짙은 안개 주의
               [날씨] 서울 개나리 활짝...내일 전국 단비 조금
               [날씨] 제주도는 벌써 '벚꽃' 봄기운 완연
               [날씨] 큰 일교차 주의 한낮 서울 20도 대전 21도
```

**5번 블록을 빼도 대기 특보와 대기 예보는 사라지지 않는다.** 제목에 대기어가 있으면
정의상 1번 경로로 들어오기 때문이다. 전수로 확인했다.

| 제목 유형 | 건수 | 경로 |
|---|---:|---|
| 미세먼지·오존·황사 **주의보/경보/특보** | 3,392 | 전량 1번(제목) |
| 미세먼지·오존·황사 **예보/농도** | 4,076 | 전량 1번(제목) |

한 건도 5번 블록에 있지 않다. 5번 블록에서 발견되는 `주의보·경보`는
**폭염 1,639 · 건조 1,054 · 한파 1,024 · 강풍 284 · 대설 279**로, 대기 특보는 **0건**이다.

**대기 행정 기사도 전부 안전하다.** 5번 블록에 한 건도 없다.

| 제목 유형 | 건수 | 5번 블록 |
|---|---:|---:|
| 비상저감조치 | 1,881 | 0 |
| 대기 경보·주의보 | 3,147 | 0 |
| 오존 | 2,485 | 0 |
| 계절관리제 | 460 | 0 |

남은 27,867건은 제목에도 본문 앞 200자에도 대기어가 없다. **93.6%는 앞 200자에
대기어가 한 번도 나오지 않는다.** 키워드 필드는 본문 전체에서 뽑히므로, 기사 말미의
「미세먼지 농도는 '보통'」 한 줄이 그대로 들어와 걸린 것이다.

**판별** — 통합분류 `사회>날씨` 이면서 제목·본문 앞 200자에 수집 키워드가 없는 기사

**전략** — 키워드 필드로 「나쁨 예보」와 「보통 예보」를 가르려는 시도는 권하지 않는다.
키워드 필드는 본문 전체에서 추출되어 말미 상투구가 그대로 들어오므로, 실제로 적용해 보면
「[날씨] 서울 응봉산 개나리 활짝」이 '나쁨·고농도'로 분류된다. 기준 문서도 이 분류가
**"완벽하지 않고 몇 %는 섞여 있다"** 고 적고 있다.

**적용 시** — 121,239건 → 93,372건(가스 사고까지 빼면 92,043건). 지수 진폭은 3.09배에서 커진다. 날씨 기사가 관심과
무관하게 매년 일정하게 생산되며 지수의 바닥을 떠받쳐 왔기 때문이다(비중 2019년 23% →
2025년 40%). 빼면 관심의 실제 감소 폭이 더 선명해진다.

## 2. 증권·테마주 — 2,590건  ← 121,239건 밖. 할 일 없음

미세먼지를 다루는 게 아니라 미세먼지로 **돈 버는** 이야기.

**판별** — 통합분류에 `증권` 또는 제목에 아래 어휘
```
코스피 · 코스닥 · 주가 · 영업이익 · 영업손실 · 증시
```

**예시**
```
[단독] 미세먼지주 50% 급등, 미리 선취매한 곳 밝혀져
미세먼지 비상저감조치 발령일 가장 많이 오른 테마주는?
자욱한 미세먼지 속 기회 찾기...스탁론으로 수혜株 담아볼까?
이른 황사에 관련株 들썩
'황사로 곳곳 미세먼지' 경보 뜨자 들썩이는 '이 종목'
```

**전략** — **제목과 분류만 보면 끝난다.** 현행 규칙에 이미 들어가 있어 선별 결과에 한 건도
남아 있지 않다. 제목 어휘로 727건, 분류 `증권`으로 1,452건, 둘 다 걸리는 것이 411건이다.
**분류가 제목보다 많이 잡는 드문 경우**로, 이 분류의 제목 대기어 비율이 16%로 전 분류
최저이기 때문이다. 2,590건 중 315건은 제목에 대기 키워드가 함께 있지만 전부 테마주 기사라
오제거가 거의 없다. 2019년에 584건으로 가장 많다.

## 3. 가스 사고 — 1,329건  ← 제거 권고

캠핑장 질식사, 차량 내 중독, 보일러 사고. **대기환경이 아니라 안전사고.**
수집 키워드에 `일산화탄소`가 있어서 제목 경로로 1,139건이 그대로 통과한다.

```
[없어야] 미세먼지 초미세먼지 PM10 PM2.5 오존 대기오염 대기질
         대기환경 공기질 황사 스모그 비산먼지 매연

[있어야] 일산화탄소 아황산가스 이산화황 이산화질소 질소산화물
         황산화물 휘발성유기화합물 VOCs 검댕 부유먼지 영농폐기물
```

**예시**
```

텐트서 숨진 4명 사망원인 '일산화탄소 중독' 추정
```

**전략** — **제목만 보고 제거된다.** 위 조건을 제목에만 걸면 967건이 잡히고, 무작위 10건을
확인한 결과 전부 실제 사고 기사였다. 나머지는 본문·키워드를 봐야 한다.

첫 조건 덕분에 「사업장 일산화탄소 배출허용기준 초과」 같은 기사는 남는다.
`대기오염 뇌졸중 증가 원인, 일산화탄소 및 미세먼지…`, `미세먼지 막으려다 질식할라`처럼
사고어를 품은 대기 기사도 대기어 조건에 걸려 구제된다.
같은 사건을 여러 매체가 반복 보도해 건수가 불어나므로, 해당 연도 지수를 실제보다 높인다.

## 4. 제품 판촉 — 48건  ← 논의 필요

**마스크·공기청정기 기사 대부분은 유지해야 한다.** 부문 정의에서 「개인 방어 — 마스크 착용,
공기청정기 구매」가 생활 부문의 핵심이기 때문이다. 제목에 마스크·공기청정기가 있는 기사
3,639건을 성격별로 갈라 보면:

| | 건수 | 판정 |
|---|---:|---|
| 기업 신제품·판촉 · 제목에 대기어 없음 | **48** | **제거 대상** |
| 기업 판촉이나 제목에 대기어 있음 | 151 | 유지 |
| 사회 현상 — 판매 급증·품귀·보급·착용 | 701 | **유지** |
| 그 외 — 마스크 쓴 시민, 외출 자제 | 2,739 | **유지** |

```
제거 대상 (48건)
   컨비니언스, '환경주의보' 마스크 6종 출시
   유해가스 차단 쑥, 전기료 뚝 쿠쿠전자 공기청정기 신제품
   코웨이, '공기청정기 IoCare' 출시

유지 (사회 현상)
   코웨이, 겨울 한파 속 공기청정기 판매량 급증
   봄날 반갑잖은 '먼지 특수'  마스크 관음죽 판매 4배 급증
   황사, 오늘 낮부터 영향 외출시 마스크 착용
   마스크 쓴 한반도 "우리 애 어린이집 보내도 될까"
```

**판별** — 제목에 **대기어가 없으면서** 기업 판촉 어휘만 있는 경우로 좁힌다.
```
[없어야]  미세먼지 초미세먼지 오존 대기질 공기질 황사 스모그 배출가스 매연
[있어야]  출시 신제품 런칭 체험단 프로모션 할인 증정 사은품 선보여
[없어야]  급증 품귀 동나 불티 매출 판매량 수요 사재기 착용 보급 지원 배포
```

마지막 줄이 핵심이다. **「판매 급증」은 시민 반응이고 「출시」는 기업 홍보**다. 앞의 것은
관심의 결과이므로 지수가 담아야 하고, 뒤의 것만 걸러낸다.

**자동차는 별도 판단이 필요하다.** 「볼보트럭, 유로6 배출가스 기준 충족 모델 출시」는
제목에 `배출가스`가 있어 위 조건으로는 걸리지 않는다. 배출 규제 대응 기사로 볼 수도,
신차 홍보로 볼 수도 있다.

## 7. 키워드 스침 — 15,610건  ← 현행 규칙에 반영됨

본문 200자에 키워드가 한 번 스쳤을 뿐 주제가 아닌 기사.

**예시**
```
IMF "9조 원 추경 필요"...홍남기 "추경 검토"      ← 본문에 미세먼지 추경 한 줄
```

**전략** — 근접·반복·대책 조건 중 하나도 못 넘기면 제거. 현행 규칙에 이미 들어가 있다.
```
근접   키워드와 상태어가 25자 이내
반복   키워드 30개 중 하나가 3회 이상
대책   키워드 + 키워드 필드에 저감·규제·단속·폐차·보조금
```

**핵심 원칙** — 제거 조건에 반드시 「대기어가 없을 것」을 붙인다. 「볼보트럭, 유로6 배출가스
기준 충족 모델 출시」는 판촉 어휘가 있지만 `배출가스`가 있어 살아남는다.

## 통합분류(카테고리)에서 판단할 것

분류는 **이미 쓰고 있다.** 다만 항상 다른 조건과 짝을 지어 쓴다.

| 쓰임 | 조건 | 현재 |
|---|---|---|
| **제거(단독)** | 통합분류 어디든 `증권` | 현행, 1,863건 |
| **통과** | `사회>날씨` + 키워드 필드에 대기어·상태어 | 5번 경로 27,867건 |
| **제거** | 부동산·연예·스포츠 등 + 본문 200자에서만 걸림 | 현행 `BADG` |
| **제거(제안)** | `사회>날씨` + 제목·본문 200자에 키워드 없음 | 1번 제거안 |

**`증권`은 분류 단독으로 되는 유일한 예외다.** 이 분류 1,863건 중 제목에 대기어가 있는
비율이 **16%**로 전 분류 최저이고, 그 16%마저 「'황사로 미세먼지' 경보 뜨자 들썩이는
'이 종목'」류의 테마주 기사다. 제목만으로는 727건밖에 못 잡는데 분류를 함께 보면
1,452건이 더 잡힌다 — `[모닝브리핑] '터키발 공포'에 세계 금융시장 요동 오늘도 낮
최고기온 38도`처럼 제목에 증시 어휘가 없는 브리핑 기사들이다.

**1번 제거안은 지금 통과 조건을 뒤집는 것이다.** 같은 `사회>날씨` 분류를 쓰되,
키워드 필드로 건져 오던 것을 그만두고 제목·본문에서 못 찾으면 빼는 쪽으로 바꾼다.

| 경제>자동차 | 3,094 | 38% |
| 사회>사건_사고 | 1,065 | 46% |

### 원칙

```
분류 단독 판정        하지 않는다
분류 + 위치 조건      한다   예) 사회>날씨 + 제목·본문에 키워드 없음 → 제거
```

**제목 경로에는 분류 조건을 걸지 않는다.** 제목에 대기어가 있으면 분류가 무엇이든
대기 기사이기 때문이다. `경제>유통` 분류의 78%가 제목에 대기어를 갖고 있다.

## 키워드 필드에서 판단할 것

기사 전문에서 뽑은 명사 목록이라 **본문 200자 제한을 넘어설 수 있다.**
다만 **위치 정보가 없어** 말미 상투구와 주제어를 구분하지 못한다.

**쓸 수 있는 경우** — 다른 조건과 결합할 때
```
날씨 블록 식별    통합분류 사회>날씨 + 키워드 필드에 대기어와 상태어
대책 기사 보강    본문에 키워드 + 키워드 필드에 저감·규제·단속·폐차
```

**쓸 수 없는 경우** — 키워드 필드 단독 판정. 385건 판독으로 모두 기각했다.
```
1차키워드 3회 이상            정밀도 17.5%
[키워드 + 농도 + 서술어]       정밀도 10%
특성추출 가중치 1–5위          정밀도 17.5%
```

**실패 사례** — 날씨 기사를 「나쁨 예보」와 「보통 예보」로 가르려 했더니
「[날씨] 서울 응봉산 개나리 활짝」이 '나쁨·고농도'로 분류됐다. 본문 말미의
"미세먼지 농도 나쁨"이 키워드 필드에 그대로 들어왔기 때문이다.

---

## 순서

```
1  제목에서 제거     증권 · 가스 사고            ← 오판 없음
2  제목에서 확정     대기어 있으면 유지          ← 정확도 92%
3  본문 200자 조건   근접 / 반복 / 대책          ← 하나도 못 넘기면 제거
4  키워드 필드 보조  날씨 블록 식별 · 대책 보강   ← 단독 판정은 금지
5  블록 단위 판단    빼기 전에 행선지부터 확인
```

**5단계가 중요하다.** 날씨 블록을 빼면 미세먼지 예보까지 사라질 것 같지만, 제목에 미세먼지가
있는 예보는 이미 1번에서 잡혀 있다. 어떤 블록을 제거하기 전에 **살리고 싶은 기사가 실제로
어느 경로로 들어오는지 먼저 세어 보아야 한다.**
